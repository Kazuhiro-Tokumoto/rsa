RSA暗号とは？

RSA暗号は、1977年にロナルド・リベスト（Rivest）、アディ・シャミア（Shamir）、レオナルド・エーデルマン（Adleman）の3人によって発明された公開鍵暗号方式です。3人の名前の頭文字を取って「RSA」と名付けられました。

公開鍵暗号とは？
暗号化に使う鍵（公開鍵）と復号化に使う鍵（秘密鍵）が異なる暗号方式です。公開鍵は誰でも使えるように公開し、秘密鍵は受信者だけが持っています。

RSA暗号の安全性の根拠

RSA暗号の安全性は「大きな数の素因数分解は非常に難しい」という数学的な性質に基づいています。

例：15 = 3 × 5 （簡単に素因数分解できる）
しかし...
200桁の数を素因数分解するのは、現在のスーパーコンピュータでも数千年かかる！

RSA暗号の仕組み

ステップ1: 鍵の生成（受信者が行う）

12つの大きな素数 p と q を選ぶ
例：p = 61, q = 53
2n = p × q を計算する
n = 61 × 53 = 3233

この n が「法（modulus）」と呼ばれ、公開鍵の一部になります。

3φ(n) = (p-1) × (q-1) を計算する
φ(3233) = 60 × 52 = 3120

φ(n) はオイラーのトーシェント関数と呼ばれます。

4φ(n) と互いに素な整数 e を選ぶ
例：e = 17

gcd(17, 3120) = 1 なので、17は適切です。

5e × d ≡ 1 (mod φ(n)) となる d を計算する
17 × d ≡ 1 (mod 3120)
d = 2753
鍵のまとめ
公開鍵：(n, e) = (3233, 17)
秘密鍵：(n, d) = (3233, 2753)
秘密情報：p, q, φ(n)

ステップ2: 暗号化

1C = Me mod n
C = 6517 mod 3233 = 2790

ステップ3: 復号化

1M = Cd mod n
M = 27902753 mod 3233 = 65
なぜ復号できるのか？
オイラーの定理により Med ≡ M (mod n) が成り立ちます。

数学的背景

フェルマーの小定理

p が素数で a が p の倍数でないとき：ap-1 ≡ 1 (mod p)

オイラーの定理

gcd(a, n) = 1 のとき：aφ(n) ≡ 1 (mod n)

中国剰余定理（CRT）

Mp = Md mod (p-1) mod p, Mq = Md mod (q-1) mod q（約4倍高速化）

セキュリティと注意点

安全な鍵長

鍵長安全性用途
512ビット危険既に解読可能
1024ビット低い推奨されない
2048ビット安全現在の標準
4096ビット非常に安全長期的な機密情報
注意: 共通の n を使い回してはいけません。
注意: 小さい e（e=3等）は攻撃に弱い。e = 65537 が推奨。
注意: 実際にはOAEP等のパディングを使用します。
