# RSA（公開鍵暗号方式）TypeScript/JavaScript実装 & Webデモ

## このリポジトリについて

「RSA」は、1977年に考案された代表的な公開鍵暗号方式です。本リポジトリでは、RSAアルゴリズムをTypeScript/JavaScriptで実装し、Webブラウザ上で実際に体験・学習できるデモ環境を提供しています。アルゴリズムの基礎理解から、実装技術・実際の暗号化／復号プロセスまで幅広く学べます。

---

## 特徴・目的

- **TypeScript/JavaScriptによるRSAの純粋な実装**
  - 暗号化・復号の主要ロジック: `rsa.ts` / `rsa.js`
  - 公開鍵・秘密鍵生成: `key.ts`
  - 素数処理・乱数生成: `primes.ts`
- **Web GUI（体験型デモ）を同梱**
  - `index.html`, `rsa.html`, `rsa_demo.html` など  
    →公開鍵暗号の流れ・しくみを視覚的に操作
    →実際にテキストの暗号化／復号を画面上で確認
- **低レベル実装・学習者向け解説**
  - アルゴリズムの根本原理や数値計算の工夫をわかりやすく
  - TypeScriptならではの型付け・開発効率も解説
- **拡張性・実験的機能**
  - WebAssembly（`wasm/`ディレクトリ）による高速化テスト
  - 画像・図解（`img/`ディレクトリ）も活用
  - サーバサイドや外部連携用途の雛形も `servers/` で準備

RSAは、公開鍵暗号方式の一つであり、1977年にロナルド・リベスト（Ron Rivest）、アディ・シャミア（Adi Shamir）、レナード・アドルマン（Leonard Adleman）の3人によって発明された暗号アルゴリズムです。RSAの名称は、発明者の3人の名前の頭文字に由来しています。RSAは、セキュリティと通信の分野で非常に広く使われている暗号方式で、特にインターネットのSSL/TLS通信や電子署名などで用いられています。

## RSAの特徴

RSAの最大の特徴は、**公開鍵暗号方式**である点で席。公開鍵暗号では、暗号化に使う鍵（公開鍵）と復号に使う鍵（秘密鍵）が異なります。これにより、秘密鍵を安全に管理しながら、公開鍵を不特定多数に公開して安全な通信を行うことが可能になります。

## RSAの数理的な基盤

RSAは、**大きな素数の積の因数分解問題**に基づいていま謹。現在のコンピュータ技術では、非常に大きな数（例えば、数百桁レベル）の素数をランダムに選び、それらを掛け合わせて得られる積を因数分解することが現実的には困難です。この「一方向性関数」の性質を利用して、暗号の安全性を確保しています。

### 鍵生成の仕組み

RSA暗号の鍵生成は以下の手順で行われます。

1. **2つの大きな素数p, qを選ぶ。**
2. これらを掛け合わせて得られる数`n = p × q`を計算する。`n`は公開鍵と秘密鍵の両方で使用される。
3. `(p-1) × (q-1)`を計算し、これをφ(n)とする。
4. φ(n)と互いに素な整数`e`（通常小さくて素数、例えば65537等）を選ぶ。これが公開鍵の指数となる。
5. `e × d ≡ 1 mod φ(n)`を満たすような`d`を求める。`d`が秘密鍵の指数になる。
6. 公開鍵は(n, e)、秘密鍵は(n, d)となる。

### 暗号化と復号

RSAの暗号化と復号は以下の通りです。

- **暗号化:**  
  メッセージをmとすると、暗号化されたメッセージcは、  
  c ≡ m^e mod n  
  で計算します。この際、mはnより小さい値でなければなりません。

- **復号:**  
  cを受け取った人は、  
  m ≡ c^d mod n  
  で元のメッセージmを復号することができます。

### 電子署名

RSAは電子署名にも利用されます。送信者はメッセージのハッシュ値を秘密鍵で暗号化し、それを署名として送ります。受信者は公開鍵で署名を復号し、メッセージのハッシュ値と一致するかどうか確認することで、送信者の本人性・改ざんの有無を検証します。

## RSAの安全性と問題点

RSAは、その安全性が「大きな素数の因数分解問題が現実的に困難である」という仮定に依拠しています。しかし、**鍵長が十分に長くない場合は、現代の計算能力を持つスーパーコンピュータを用いると突破される可能性があります**。実務では最低でも2048ビット以上の鍵長が推奨されています。

また、RSA自体は暗号強度は高いですが、実装ミスやパディング方式の脆弱性（例：PKCS#1 v1.5パディングのBleichenbacher攻撃）などからセキュリティが損なわれる場合もあります。そのため、仕様遵守やセキュアな実装が求められます。

現代では、RSAの処理速度や鍵サイズの面から、楕円曲線暗号（ECC）などの新しい公開鍵暗号方式も広く使われつつありますが、まだ多くのシステムでRSAが重要な役割を果たしています。

## まとめ

RSA暗号は、公開鍵と秘密鍵を使った暗号・電子署名方式であり、その安全性は大きな素数の因数分解の困難性に依存しています。実際の運用においては鍵管理や実装の安全性にも注意を払う必要があります。暗号通信、電子署名、データの機密性・認証・改ざん防止など、広範囲な分野で基盤技術として利用されています。
